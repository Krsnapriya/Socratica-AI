javascript JavaScript API Reference

common.js

  • toggleTheme() — dark/light mode toggle
  • initKeyboard — Cmd+K search, Escape close
  • initSelects — select change dispatch
  • initSwitchTier — Tier 1/2 toggle

socratic-engine.js

  • SocraticEngine.getData() — full state
  • SocraticEngine.switchProblem(id) — change problem
  • SocraticEngine.simulateResubmit() — new round
  • SocraticEngine.setTier(n) — 1 or 2
  • bindSocraticEngine() — bind to DOM

rocket_launch Quick Start

Demo Walkthrough

  1. Start at Curriculum Dashboard
  2. Navigate to Workspace to see the IDE
  3. Click RUN_TESTS or TRACE_EXECUTION to go to Trajectory View
  4. Click RESUBMIT to advance rounds through the convergence timeline
  5. Check Settings for user identity management
